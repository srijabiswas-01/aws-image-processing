AWS AUTOMATED IMAGE PROCESSING

Upload once. Get two processed images.

Upload a JPG, JPEG or PNG image. AWS will automatically create an 800×800 maximum resized colour image and a black-and-white version. The original and processed files are stored in Amazon S3, processing is handled through SQS and AWS Lambda, metadata is stored in Amazon RDS, and an SNS email notification is sent when processing completes.
